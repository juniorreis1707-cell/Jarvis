Resumir Página Web

Use esta skill quando o usuário pedir para resumir, explicar ou dar a ideia
geral de uma página ou site.

Passos:
1. Use a ferramenta abrir_pagina com a URL informada (ou pesquisada).
2. Use extrair_texto_pagina para ler o conteúdo.
3. Escreva um resumo de no máximo 5 frases, focando no propósito principal
   da página e nas informações mais relevantes.
4. Se o texto extraído for muito curto ou parecer um erro (ex: página de
   login, captcha), avise o usuário em vez de inventar um resumo.
