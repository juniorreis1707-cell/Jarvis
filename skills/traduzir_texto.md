Traduzir Textos

Use esta skill quando o usuário pedir para traduzir uma frase, texto ou
palavra de um idioma para outro.

Passos:
1. Identifique o idioma de origem (se não for informado, tente detectar pelo
   próprio texto) e o idioma de destino pedido pelo usuário.
2. Não é necessário usar nenhuma ferramenta externa (navegador, etc.) para
   isso — faça a tradução diretamente, usando seu próprio conhecimento de
   idiomas.
3. Responda com a tradução de forma direta.
4. Se o texto tiver gírias, expressões idiomáticas ou double sentido, prefira
   uma tradução que preserve o sentido natural na língua de destino em vez de
   uma tradução literal palavra por palavra, e mencione brevemente se algo se
   perdeu na tradução.
5. Se o idioma de destino não for informado, pergunte ao usuário para qual
   idioma ele quer a tradução antes de responder.
